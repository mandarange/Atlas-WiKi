# Atlas WiKi v0.1.5 Release Notes

## Stabilization Scope

v0.1.5 closes the ATW-95 stabilization surface for RAG, Gemini embeddings, persistent vector indexes, Supabase chunks/pgvector migrations, structured schema contracts, MCP actor-aware authorization, package smoke coverage, and release evidence reproducibility.

## Upgrade Notes

- Run `npm run release:check` before tagging or publishing.
- Re-run `awiki rag index` after upgrading if you use vector or hybrid RAG; embedding profiles are keyed by provider, model, dimensions, and prompt policy.
- For Gemini, prefer `gemini-embedding-2`. Atlas WiKi sends only `outputDimensionality` for that model and uses task config only for `gemini-embedding-001`.
- For Supabase, apply all committed migrations through `20260527000700_atlas_wiki_rag_pgvector.sql` before relying on chunk search or stored embeddings.

## Known Limits

Supabase hosted deployments still need project-local RLS/RPC verification. Offline tests cover the adapter and policy re-check path, while `SUPABASE_LOCAL_TESTS=1 npm run test:supabase:local` is the release operator gate for a live local Supabase project.

## Verification Contract

- `npm run typecheck`
- `npm run test:rag`
- `npm run test:structured`
- `npm run test:supabase:mock`
- `npm run test:mcp`
- `npm run package:smoke`
- `npm run release:next-stable-verify`
- After publish: `ATLAS_WIKI_PUBLISHED_SPEC=atlas-wiki@0.1.5 npm run release:published-check`
