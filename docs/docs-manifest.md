# Documentation Manifest

The documentation gate covers architecture, SQLite storage, security model, ACL model, schema, ingestion, retrieval, MCP, SDK, CLI, connectors, audit model, backup/restore, deployment, adapter boundary, and migration from SKS.

Each document must provide an artifact, a core link, a security note, a verification note, and operator notes. `tests/docs-coverage.test.ts` checks this manifest and the required files.
