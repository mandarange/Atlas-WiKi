# Atlas WiKi v0.1.0 Release Notes

Atlas WiKi v0.1.0 establishes the TypeScript-first npm package, SQLite source-of-truth store, CLI, SDK, MCP server surface, schema registry, ACL-before-context retrieval, redaction, freshness/conflict markers, audit-chain validation, and package smoke gates.

## Release Gate

The release candidate must pass `npm run release:check`, `npm run packcheck`, and `npm run selftest -- --mock`.

## Known Constraints

`node:sqlite` is still marked experimental by Node.js at runtime. Atlas WiKi pins Node.js 24+ and keeps SQLite access behind a narrow storage module so the driver can be swapped later if Node changes that surface.
