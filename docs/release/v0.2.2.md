# Atlas WiKi v0.2.2

v0.2.2 is a backward-compatible user-facing Supabase setup release candidate. It prepares the package for publish but does not publish it.

## Added

- `awiki supabase init --out ./supabase --json`
- `awiki supabase migrations export --out ./supabase/migrations --json`
- `awiki supabase migrations list --json`
- `awiki supabase doctor --url $SUPABASE_URL --key $SUPABASE_ANON_KEY --json`
- `awiki supabase status --json`
- Typed Supabase migration asset helpers from `atlas-wiki/supabase`

## Fixed

- npm tarballs now include `supabase/migrations`.
- README separates npm-only Supabase setup from repo-clone setup.
- Structured extraction examples use executable customer profile sample text.
- CLI startup reports a friendly Node.js 24+ error before SQLite-backed imports.
- Supabase dimension guidance consistently names the `atlas_wiki_default_1536` policy.

## Gates

- `npm run typecheck`
- `npm run build`
- `npm run test`
- `npm run test:rag`
- `npm run test:structured`
- `npm run test:supabase:mock`
- `npm run package:verify`
- `npm run package:smoke`
- After publish only: `ATLAS_WIKI_PUBLISHED_SPEC=atlas-wiki@0.2.2 npm run release:published-check`
