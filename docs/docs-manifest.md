# Documentation Manifest

The documentation gate covers architecture, SQLite storage, security model, ACL model, schema, ingestion, retrieval, MCP, MCP security, MCP production auth, SDK, CLI, connectors, audit model, audit chain, backup/restore, migration policy, npm publishing, release reproducibility, published package smoke, policy matrix, known limits, production hardening, production hardening completion, deployment, adapter boundary, and migration from SKS.

Each document must provide an artifact, a core link, a security note, a verification note, and operator notes. `tests/docs-coverage.test.ts` checks this manifest and the required files.
