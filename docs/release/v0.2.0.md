# Atlas WiKi v0.2.0 Release Notes

## N9 Closure Scope

v0.2.0 closes the N9 total-closure surface for release evidence v2, async RAG status, StoreContract v2, Supabase chunk/vector RPC runtime paths, schema contract registry, and package smoke coverage.

## Breaking Changes

- `AtlasWiki.ragStatus()` is now async so Supabase and other async stores report real vector stats instead of sync zero fallbacks.
- Store backends implement the v2 retrieval contract: `searchChunks`, `vectorSearch`, async `ragVectorStats`, `upsertRecordCas`, and schema registry methods.

## Upgrade Notes

- Replace direct sync `wiki.ragStatus()` reads with `await wiki.ragStatus()`.
- Use `wiki.ragStatusSync()` only where a sync Memory/SQLite compatibility path is acceptable.
- Re-run `awiki rag index` after upgrading if you use vector or hybrid RAG.
- For Supabase, apply migrations through `20260527000800_atlas_wiki_n9_rpc_contracts.sql` before relying on runtime chunk/vector RPC search.
- Supabase pgvector support officially targets the default 1536-dimension profile; custom dimensions require an explicit project migration.

## Known Limits

Postpublish evidence, npm `gitHead`, target tag head, CI run URL, and GitHub Release asset attachment are external release gates. They are enforced by `.github/workflows/publish.yml` and by `ATLAS_WIKI_REQUIRE_EXTERNAL_RELEASE_EVIDENCE=1 npm run release:next-stable-verify`.

## Verification Contract

- `npm run typecheck`
- `npm run test:rag`
- `npm run test:structured`
- `npm run test:supabase:mock`
- `npm run test:mcp`
- `npm run package:smoke`
- `npm run release:next-stable-verify`
- After publish: `ATLAS_WIKI_PUBLISHED_SPEC=atlas-wiki@0.2.0 npm run release:published-check`
